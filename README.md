# SVS SHOP FAST

## Overview

SVS SHOP FAST is a simple e-commerce website developed using HTML, CSS, and JavaScript. The application allows users to browse products, add items to cart and wishlist, place orders, manage reviews, and contact customer support.

## Features

* User Registration and Login
* Product Listing
* Product Search
* Shopping Cart Management
* Wishlist Management
* Order Placement and Cancellation
* Product Reviews
* Contact Us Page
* Local Storage Data Persistence

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage API

## How to Run

1. Download the project files.
2. Open `index.html` in a web browser.
3. Browse products and use the application features.
